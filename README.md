# DSS MODULAR 2

Desktop systems developed in C# with Windows Forms, integrated with a MySQL database for managing information related to clients, products, inventory, and restaurant billing.

The projects were developed in the context of the Systems Development Technician course, aiming to apply programming concepts, graphical user interface development, and relational data manipulation.

## Modules

* **/ESTOQUE**: System for customer, product, and inventory management.
* **/RESTAURANTE**: Restaurant management, billing, and receipt generation system.

## Technologies

* C# (.NET Framework / Windows Forms)
* MySQL (MySqlConnector / ADO.NET)
* Visual Studio
